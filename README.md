# andrews-bakery.king.orchestrate.ca

Built live by the Orchestrate Solutions agent team in an Orchestrate demonstration. Static site: HTML, CSS and JavaScript.

## Structure
- `index.html` home; `pages/story|menu|visit|cake|faq.html`; `js/tools/*.js` working features (stay in the browser).
- Every page links `css/tokens.css`, `css/layout.css`, `css/site.css`, and `js/nav.js`, `motion.js`, `app.js` (deferred); `js/nav.js` adds the shell.
- No phone, email or address was given: nothing here invents them.
